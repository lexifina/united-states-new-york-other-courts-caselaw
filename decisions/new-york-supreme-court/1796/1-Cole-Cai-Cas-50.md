# Cohan v. Kip

## Majority (Per Curiam.)

Per Curiam.
A plaintiff may .accept or refuse an imperfect copy of a plea; and if he accepts it, the court will compel the defendant to file a perfect plea, if that has not already been done. Here appears to have been a mere mistake on the part of the defendant. Let him file a plea instanter, and the default be set aside on payment of costs.
