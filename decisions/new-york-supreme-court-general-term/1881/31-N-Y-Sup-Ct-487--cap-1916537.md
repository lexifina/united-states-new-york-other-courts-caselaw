# Barlow v. Barlow

## Majority

So much of the order appealed from as refuses to set aside the order for the publication of the summons, affirmed; and so much of said order as refuses to set aside the attachment, reversed, and the attachment set aside with ten dollars costs, but with costs of this appeal to neither party.
