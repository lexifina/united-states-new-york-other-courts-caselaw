# People ex rel. New York Elevated Railroad v. Coleman

## Majority (Daniels, J.)

Daniels, J.
The order from which the appeal has been taken in this case contains the same provisions as the order in the Case of the Manhattan Railway Company already considered. 16 N. Y. State Rep., 135. It requires no further attention for its disposition, but so far as the order provides for a reference it should be affirmed, but in all other respects reversed, without costs to either party.
Van Brdnt, P. J., and Brady, J., concur.
