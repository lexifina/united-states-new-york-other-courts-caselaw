# Faxon v. Mason

## Majority

No opinion. Order modified so as to deny the motion, unless defendant Ball, within five days, file return on appeal, and execute undertaking on appeal, in which case motion granted. The order, as so modified, affirmed, without costs. See 21 N. Y. Supp. 737; 27 N. Y. Supp. 1025.
